# 🚀 VLESS to Xray JSON Converter
### تبدیل‌گر هوشمند لینک‌های VLESS به کانفیگ کامل Xray-core

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue?logo=github)](https://pages.github.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

یک ابزار تحت وب قدرتمند، سریع و امن برای تبدیل لینک‌های `vless://` و ساب‌اسکریپشن‌های Base64 به کانفیگ استاندارد **Xray-core** با قابلیت‌های پیشرفته مسیریابی (Routing)، انتخاب DNS، و بهینه‌سازی خودکار.

---

## ✨ ویژگی‌های کلیدی

### 🔧 تبدیل و پردازش
- ✅ پشتیبانی از تمام پروتکل‌های VLESS (WS, gRPC, TCP, HTTP/2, Reality, TLS)
- ✅ استخراج خودکار از لینک‌های ساب‌اسکریپشن (Base64 Decode)
- ✅ تولید کانفیگ کامل شامل `inbounds`, `outbounds`, `routing`, `dns`, `observatory`
- ✅ تولید تگ‌های خودکار با پیشوند دلخواه
- ✅ مدیریت خطاهای هوشمند و نادیده گرفتن لینک‌های نامعتبر

### 🌐 دریافت ورودی پیشرفته
- 📥 **دریافت از URL**: پشتیبانی از لینک‌های ساب‌اسکریپشن مستقیم (با دور زدن CORS)
- 📂 **Drag & Drop**: کشیدن و رها کردن فایل‌های متنی یا JSON
- 📋 **پیست مستقیم**: پشتیبانی از کلیپ‌بورد
- 💾 **ذخیره خودکار**: بازیابی خودکار داده‌ها پس از بستن مرورگر (LocalStorage)

### ⚙️ تنظیمات سفارشی‌سازی
- 🖥 **انتخاب DNS Server**: ۷ پری‌ست آماده (Cloudflare, Google, Shecan, AdGuard, ...) + حالت سفارشی
- 🎯 **Test URL قابل تنظیم**: تغییر آدرس تست سلامت (Google, Cloudflare, Apple, ...)
- ⏱ **Probe Interval**: تنظیم بازه زمانی بررسی سلامت گره‌ها (۱ تا ۳۰ دقیقه)
- 🔒 **امنیت**: گزینه `allowInsecure` برای اتصالات TLS

### 📊 آنالیز و نمایش
- 🔍 **جستجو و فیلتر**: فیلتر کردن گره‌ها بر اساس نام، آدرس، پروتکل و امنیت
- 🎨 **نمایش دوگانه**: نمای رنگی (Syntax Highlighted) و متن ساده JSON
- 📈 **آمار لحظه‌ای**: نمایش تعداد گره‌های معتبر، حجم خروجی و زمان پردازش
- 🛡 **امنیت بصری**: مخفی‌کردن بخش‌های حساس UUID در صورت نیاز

### 🚀 خروجی
- 📥 دانلود فایل `final_sub.json` آماده اجرا در Xray-core
- 📋 کپی سریع در کلیپ‌بورد
- 🔄 سازگار با کلاینت‌های: v2rayNG, Nekoray, Hiddify, Streisand, Shadowrocket

## 📖 راهنمای استفاده

### ۱. وارد کردن لینک‌ها
- **روش اول**: لینک ساب‌اسکریپشن خود را در کادر ورودی پیست کنید.
- **روش دوم**: روی دکمه **"دریافت از URL"** کلیک کرده و لینک ساب را وارد کنید تا به صورت خودکار دانلود و پردازش شود.
- **روش سوم**: فایل متنی حاوی لینک‌ها را بکشید و در کادر رها کنید (Drag & Drop).

### ۲. تنظیمات اختیاری
- **پیشوند تگ**: نام‌گذاری خودکار اوت‌باندها (مثلاً `proxy-1`, `my-vless-1`).
- **DNS Server**: سرور DNS مورد نظر خود را از لیست انتخاب کنید (پیشنهاد: Cloudflare یا Shecan برای ایران).
- **Test URL**: آدرسی که Xray برای تست سلامت گره‌ها استفاده می‌کند را تغییر دهید.
- **Allow Insecure**: اگر گره‌های شما گواهی SSL نامعتبر دارند، این گزینه را فعال کنید.

### ۳. تولید و دریافت خروجی
- روی دکمه **"⚡ تولید کانفیگ JSON"** کلیک کنید.
- لیست گره‌های شناسایی شده در پایین صفحه نمایش داده می‌شود (قابل جستجو و فیلتر).
- خروجی JSON را در تب‌های "نمای رنگی" یا "متن ساده" مشاهده کنید.
- با دکمه **"⬇ final_sub.json"** فایل را دانلود کرده یا با **"⧉ کپی"** در کلیپ‌بورد کپی کنید.
