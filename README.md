# 🚀 VLESS to Xray JSON Converter
### تبدیل‌گر هوشمند لینک‌های VLESS به کانفیگ کامل Xray-core

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue?logo=github)](https://pages.github.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

یک ابزار تحت وب قدرتمند، سریع و امن برای تبدیل لینک‌های `vless://` و ساب‌اسکریپشن‌های Base64 به کانفیگ استاندارد **Xray-core** با قابلیت‌های پیشرفته مسیریابی (Routing)، انتخاب DNS، و بهینه‌سازی خودکار.

---

## ✨ ویژگی‌های کلیدی

### 🔧 تبدیل و پردازش
- ✅ پشتیبانی از تمام پروتکل‌های VLESS (WS, gRPC, TCP, HTTP/2, Reality, TLS)
- ✅ استخراج خودکار از لینک‌های ساب‌اسکریپشن (Base64 Decode)
- ✅ تولید کانفیگ کامل شامل `inbounds`, `outbounds`, `routing`, `dns`, `observatory`
- ✅ تولید تگ‌های خودکار با پیشوند دلخواه
- ✅ مدیریت خطاهای هوشمند و نادیده گرفتن لینک‌های نامعتبر

### 🌐 دریافت ورودی پیشرفته
- 📥 **دریافت از URL**: تلاش خودکار از چند مسیر پروکسی (با نمایش وضعیت هر مسیر و تایم‌اوت)
- 📂 **Drag & Drop**: کشیدن و رها کردن فایل‌های `.txt` و `.json` (ساختار `configs` هم شناسایی می‌شود)
- 📋 **پیست مستقیم**: خواندن از کلیپ‌بورد با fallback امن
- ⏳ **حافظه موقت**: متن دریافتی فقط در `sessionStorage` **همان تب** و حداکثر ۵ دقیقه نگه داشته می‌شود (با دکمه حذف فوری)

### ⚙️ تنظیمات سفارشی‌سازی
- 🖥 **انتخاب DNS Server**: ۶ پری‌ست آماده (Cloudflare, Google, Quad9, Shecan, Electro, Radar) + تست پینگ زنده
- 🎯 **Test URL قابل تنظیم**: انتخاب آدرس تست سلامت (Google gstatic یا Cloudflare)
- ⏱ **Probe Interval**: بازه بررسی سلامت گره‌ها (۱، ۳ یا ۵ دقیقه)
- 🧩 **قالب‌های آماده**: استاندارد / استریمینگ / مینیمال با یک کلیک
- 🔒 **امنیت**: گزینه `allowInsecure` برای اتصالات TLS

### 📊 آنالیز و نمایش
- 🔍 **جستجو**: فیلتر گره‌ها بر اساس نام، آدرس و پروتکل
- ☑️ **انتخاب گره‌ها**: روشن/خاموش کردن هر گره (یا همه/هیچ)؛ فقط گره‌های انتخاب‌شده وارد خروجی می‌شوند
- 🎨 **سه نما**: کد رنگی، متن خام، و **diff** نسبت به تولید قبلی
- 📈 **آمار لحظه‌ای**: تعداد ورودی، گره سالم، نامعتبر و تکراری

### 🚀 خروجی
- 📦 چهار قالب: **Xray-core JSON**، **Sing-Box JSON**، **Clash Meta YAML**، لیست Base64
- 📥 دانلود فایل با پسوند و MIME درست
- 📋 کپی سریع در کلیپ‌بورد + 📷 QR (متن‌های بلند خودکار صفحه‌بندی می‌شوند)
- 🔄 سازگار با کلاینت‌های: v2rayNG, Nekoray, Hiddify, Streisand, Shadowrocket

## 📖 راهنمای استفاده

### ۱. وارد کردن لینک‌ها
- **روش اول**: لینک‌ها یا محتوای Base64 ساب را در کادر ورودی پیست کنید.
- **روش دوم**: آدرس ساب را در کادر بالا وارد کرده و **«⬇ دریافت»** را بزنید.
- **روش سوم**: فایل `.txt` یا `.json` را بکشید و در کادر رها کنید (Drag & Drop).
- **روش چهارم**: دکمه **«📋 پیست مستقیم»** (یا `Ctrl+V` داخل کادر).

### ۲. تنظیمات اختیاری
- **پیشوند تگ**: نام‌گذاری خودکار اوت‌باندها (مثلاً `proxy-1`, `my-vless-1`).
- **DNS Server**: سرور DNS مورد نظر را انتخاب کنید (پیشنهاد: Cloudflare یا Shecan برای ایران) و با **«📡 تست DNS»** پینگ زنده بگیرید.
- **Test URL و Probe Interval**: آدرس و بازه‌ای که برای تست سلامت گره‌ها استفاده می‌شود.
- **Routing**: مسدودسازی تبلیغات، direct شدن سایت‌های ایران، بلاک QUIC و ترافیک خصوصی.
- **Allow Insecure**: اگر گره‌هایتان گواهی نامعتبر دارند این گزینه را فعال کنید.

### 🚀 بهینه‌سازی سرعت
> ⚠️ واقع‌بینانه: هیچ کانفیگی نمی‌تواند سرور کند را سریع کند. سقف سرعت را کیفیت گره و مسیر شبکه تعیین می‌کند. این بخش **سربار را کم** و **انتخاب گره خوب را ممکن** می‌کند.

- **TCP Fast Open** — یک رفت‌وبرگشت (RTT) از زمان برقراری هر اتصال کم می‌کند.
- **MPTCP** — اگر دستگاه هم‌زمان وای‌فای و دیتا دارد، هر دو مسیر را ترکیب می‌کند.
- **Keep-Alive** — از قطع شدن اتصال‌های بی‌کار توسط NAT/اپراتور جلوگیری می‌کند.
- **بافر هر اتصال** — بافر بزرگ‌تر روی لینک‌های پرتأخیر توان (throughput) را بالا می‌برد.
- **IP جایگزین (Clean IP)** — بیشترین اثر را روی گره‌های پشت Cloudflare دارد؛ سرعت به IP لبه‌ای که دامنه به آن resolve می‌شود بستگی دارد. SNI و هدر `Host` دست‌نخورده می‌مانند، پس TLS درست کار می‌کند. مقدار نامعتبر (مثلاً `example.com`) نادیده گرفته می‌شود تا کانفیگ نشکند.
- **📡 سنجش تأخیر گره‌ها** — زمان دسترسی مرورگر تا هر میزبان را اندازه می‌گیرد، روی کارت‌ها نشان می‌دهد و با **«⚡ انتخاب ۱۰ گره سریع‌تر»** فقط بهترین‌ها را نگه می‌دارد. این کار هم گره‌های مرده را از کانفیگ بیرون می‌کند و هم بارِ health-check روی ۱۹۱ گره را از بین می‌برد.
  - این سنجش **بدون VPN** انجام می‌شود: معیار مقایسه است، نه تضمین سرعت تونل.
  - از صفحه HTTPS، گره‌های بدون TLS به‌دلیل mixed-content قابل سنجش نیستند و «غیرقابل سنجش» گزارش می‌شوند.
  - توجه: این تست IP شما را مستقیم به سرور نشان می‌دهد.

### ۳. تولید و دریافت خروجی
- گره‌های شناسایی‌شده در کارت‌های جدا نمایش داده می‌شوند؛ با کلیک روی هر کارت می‌توانید آن را از خروجی **حذف/اضافه** کنید (یا از دکمه‌های «همه»/«هیچ» استفاده کنید).
- قالب خروجی را از کشوی کنار **«📋 کپی متن»** انتخاب کنید: Xray / Sing-Box / Clash / لیست Base64.
- **«⚡ شروع تبدیل و کپی کانفیگ»** خروجی را می‌سازد و در کلیپ‌بورد می‌گذارد.
- تب **«تغییرات Δ»** تفاوت با تولید قبلیِ همان قالب را نشان می‌دهد.

## 🧪 تست‌ها

تست‌ها **بدون هیچ وابستگی npm** و با رانر داخلی Node نوشته شده‌اند؛ منطق واقعیِ داخل `index.html` روی داده‌های واقعی `json_configs/configs_1.json` اجرا می‌شود (یک DOM حداقلی در `tests/harness.mjs` شبیه‌سازی شده است):

```bash
npm test                      # یا مستقیم:
node --test tests/ui.test.mjs
```

پوشش تست‌ها: پارس ۱۹۱ کانفیگ واقعی، شمارش تکراری/نامعتبر، دکود Base64، تشخیص پرچم کشور، عدم تزریق HTML از طریق ریمارک، درستی خروجی هر سه قالب (Xray/Sing-Box/Clash)، اثر واقعی کلیدهای Routing، رفتار انتخاب گره‌ها، صفحه‌بندی QR و بازیابی تم.

برای مقایسه خروجی با یک نسخه دلخواه از `index.html`:

```bash
node tests/baseline.mjs /tmp/out.json [path/to/index.html]
```

## 🛠 تکنولوژی‌های استفاده شده

- **HTML5 / CSS3**: ساختار معنایی، متغیرهای CSS برای سه تم، و طراحی واکنش‌گرا
- **Vanilla JavaScript**: بدون وابستگی به فریم‌ورک (بدون jQuery/React/Vue و بدون بیلد)
- **وزیرمتن**: فونت فارسی از jsDelivr به‌صورت غیرمسدودکننده با `font-display: swap` (در دسترس نبودن CDN فقط به فونت پیش‌فرض سیستم ختم می‌شود)
- **Canvas API**: پس‌زمینه ذره‌ای که با `prefers-reduced-motion` و پنهان شدن تب متوقف می‌شود
- **Storage**: تم در `LocalStorage`؛ متن ساب فقط در `sessionStorage` همان تب با انقضای ۵ دقیقه
- **Blob API**: تولید و دانلود فایل
- **Node test runner**: تست‌ها بدون وابستگی خارجی (`tests/`)
